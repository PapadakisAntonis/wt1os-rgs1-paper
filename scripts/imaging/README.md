# Imaging analysis

ImageJ macros used for image quantification. Both run in Fiji, process every `.tif` in the selected folder and its subfolders, and write results to a new `Analysis` subfolder.

## actin_cytoskeleton_analysis.ijm

Input: two-channel images, channel 1 = nuclei, channel 2 = phalloidin.

## colocalization_nucleus_WT1AS.ijm

Input: two-channel images, channel 1 = nucleus, channel 2 = WT1AS.
